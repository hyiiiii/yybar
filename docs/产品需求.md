# yybar 产品需求

> 描述当前已交付版本的功能范围与边界。新需求迭代时以本文为准；与代码不一致以代码为准并同步回这里。

---

## 0. 产品定位

- **形态**：常驻菜单栏的小工具（Accessory App，不占 Dock）。
- **平台**：macOS 14 Sonoma+（依赖 SwiftUI `MenuBarExtra(.window)`、`@Observable`、`SMAppService`）。
- **设计**：以 macOS HIG 为底座，关键信息层（百分比、进度、KPI、HUD）按设计稿落地自绘组件；非关键层（Picker / Toggle / DatePicker / TabView / Material）全部用系统默认。
- **一句话价值**：装上它 → 不打开 CLI 也能随时看到 Codex / Claude Code / Grok 还剩多少额度、今天和本周花了多少钱。

## 1. 账号自动识别

- 启动时扫描本机已有的 Codex / Claude Code / Grok 凭据：
  - Codex：`~/.codex/auth.json`（OAuth 模式，解析 JWT 拿邮箱 / plan / accountId）。
  - Claude：先读 `~/.claude/.credentials.json`；不存在则读 macOS Keychain 通用密码项 `Claude Code-credentials`（service name）。邮箱兜底从 `~/.claude.json` 顶层 `oauthAccount.emailAddress` 读取。
  - Grok：读 `~/.grok/auth.json` 中的 first-party xAI 账号（`https://auth.x.ai::…`），用其中的 API key 请求云端额度。过期时委托已安装的 `grok models` 只读命令续期，不发起对话。
  - Gemini / agy（2026-10 新增，只显示额度）：额度挂在 Google 账号上，通过本机 agy CLI 的只读命令 `agy -p /usage --output-format json` 读取，yybar 不碰 Google 凭据。只有两个池子：Gemini 模型（Pro 和 Flash 共用）→ Gemini 格子；Claude + GPT 模型 → agy 格子；各有 5 小时和每周两层限制。本机有 agy CLI（`~/.local/bin`、`/opt/homebrew/bin`、`/usr/local/bin`）时 agy 默认启用，另有 `/Applications/Gemini.app` 时 Gemini 也默认启用。
  - Grok Bot（2026-10 新增，只显示额度，**额度暂未接通**）：Grok Bot 桌面 App 用 Cursor 账号登录，每周额度来自 `api2.cursor.sh` 的 `DashboardService/GetSandUsageStatus`（App 自己「设置 → 用量与账单」用的同一接口），解析已写好；但 App 的登录 token 用 Electron safeStorage 加密存放，读取需要解密，这一步尚未实现，界面显示「未接通」。本机有 `/Applications/Grok Bot.app` 时默认启用。
  - 用量统计：Gemini / Antigravity 读本机 agy CLI 的会话库（只读每次调用的 token 数、模型和时间，不读对话内容），按工具归属：agy 里的所有调用（包括 Gemini 3.8 Flash 等 Gemini 模型）都记到 Antigravity；Gemini 只统计 Gemini 自己的客户端，Gemini.app 本地数据加密读不到，所以目前恒为 0。额度格子仍按 agy 的两个池子分（Gemini 模型池 → Gemini 格子，Claude + GPT 池 → Antigravity 格子），因此在 agy 里用 Gemini 模型时，额度扣在 Gemini 格子、token 记在 Antigravity。Grok Bot 在云端运行，本机无日志，用量统计里恒为 0。
- 不做 App 内登录流程。前提：用户已经在终端跑过 `codex login` / `claude` / `grok login`（Gemini / agy 需 agy 已用 Google 账号登录）。
- 用户可在「设置 → 账号」勾选要显示的服务；关闭后该服务在菜单栏、Popover、悬浮窗、统计中均不出现，也不查询其 API。
- 首次启动若不存在 `~/.claude/.credentials.json`，且尚未提示过，会先弹一次说明性 Alert（"接下来 macOS 会弹 Keychain 授权窗口，请选择始终允许"），再触发系统 Keychain 弹窗。

## 2. 菜单栏标签

- 标签是模板图像（template NSImage），自适应深浅菜单栏。
- 顺序固定：**Codex → Claude → Grok → Grok Bot → Gemini → agy**。
- 每段为 `<服务 logo>  <百分比>`：
  - Logo 用项目内置的 `codex.svg` / `claude.svg` / `grok.svg`（不是 SF Symbol，保留服务的颜色辨识度——菜单栏会做模板化变灰）。
  - 百分比用 `monospacedDigit`。
  - Grok 没有 5 小时窗口，菜单栏始终显示其云端当前计费周期剩余百分比；Grok Bot 同样只有周额度。Gemini / agy 和 Codex / Claude 一样按 5H / WK 设置显示。
  - Grok Bot / Gemini / agy 的 logo 是项目内置的占位矢量图（`grokBot.svg` / `gemini.svg` / `agy.svg`，不是官方 logo，后续可替换）。
- 设置项：
  - 显示哪个服务（Codex / Claude / Grok / Grok Bot / Gemini / agy，可分别开关）。
  - 显示哪个额度窗口：5 小时 / 周窗口 / 两者（`5h/1w` 斜杠拼接）；该选项只作用于 Codex / Claude。
- 都关闭时仍保留一个占位 logo，避免菜单栏完全消失。
- 使用中呼吸（Codex 呼吸色：深色栏 #48484A、浅色栏 #AEAEB2）：某服务的本地会话日志在最近 30 秒内有写入时，菜单栏里该服务的 logo 在原色和识别色之间呼吸闪烁（1.6s 一周期），写入停止后自动停止。等待审批时（日志最后是还没有结果的工具调用，且 3 秒没有新写入）图标保持识别色不呼吸，有新写入后恢复；最多保持 30 分钟，由设置 · 显示「等待审批保持颜色」单独控制（默认开）。长时间运行且不写日志的工具也会被当成等待审批。设置 → 显示 →「使用中图标呼吸」可关闭，默认开启。

- 原 Popover 顶部的刷新按钮和「x 前已刷新」移到主窗口侧边栏底部。
- 主窗口侧边栏可隐藏：标题栏左侧按钮或 ⌃⌘S。
- 统计、设置各为一个大页：所有部分纵向排列，侧边栏点哪项就平滑滚动到哪项，手动滚动时侧边栏高亮跟随当前部分。统计页顶部固定时间范围 + 服务筛选，作用于整页（Token 活动只跟随服务筛选）。
- 统计页服务筛选按钮上的小色块换成官方服务状态圆点（设置 · 显示 · 统计 ·「服务状态圆点」控制，关闭或未拉到时为灰点）；「弹出窗口」设置分组改名为「统计」（重置时间显示、服务状态圆点）。
- 「缓存读取」KPI 也带按服务拆分细条；按服务、今天 vs 近 7 日均值、每日用量图例 / 浮层里的色块换成菜单栏同款服务 logo（染识别色）。
- 「其他账号」的「启用」开关含义改为：刷新该账号的额度。
- 2026-10 概览「今天」火苗：「今天」标题旁一个 🔥,按今天全部服务的全部 Token(含缓存)落在 Token 活动热力图的哪一档(1~4 档，最近一年有用量的日子按 25% / 50% / 75% 分位)显示：档位越高颜色越深(金橙 → 橙黄 → 橙 → 原生 🔥)、烧得越旺，3 档起冒火星;今天还没用时只有一个灰色小炭点。火苗是真实燃烧的效果(火舌舔动、往上窜，不是左右晃),底部和「今天」两字底部对齐，悬停显示今天的 Token 数和档位。只在时间范围为「今天」时出现。Token 活动选「全部」时热力图也改用对应的暖色四档(浅琥珀 → 橙 → 深橙 → 红)，和火苗一一对应;选单个服务时仍用该服务识别色。
- 2026-10 账号续费日：设置 · 账号每行订阅标签后用同样的小长条显示下次续费日。Codex 取 ChatGPT 登录令牌里的付费周期结束日(准确，如「10月20日续费」);Claude 接口只给订阅开始日，按每月同一天推算(显示同样不加「约」,悬停说明是推算;年付或改过套餐时可能不准);订阅标签按档次用不同颜色区分;Grok 接口没有订阅续费信息，不显示；免费账号不显示。3 天内续费显示橙色，悬停说明来源。

## 3. Popover 总览

- 点击菜单栏图标弹出宽 340pt 的窗口。
- 顺序：Codex → Claude → Grok（每个服务一个 block，用 Divider 分隔）。
- Header 一行：标题「Usage / 用量」+ 副标题（最近一次刷新相对时间）+ 状态点（live / stale / offline）+ 三个一级图标按钮（刷新 / 统计 / 设置）+ ⋯ kebab 菜单（退出）。
- 每个 block 字段：
  - 服务 tile + 服务名 + 副标题（Provider · Plan）。
  - 5 小时窗口：38pt 剩余百分比 + 进度条 + 重置倒计时 + 「今日 cost」+「本周 cost」。
  - 周窗口：缩小版进度条 + 百分比 + 重置时间。
  - Grok 用云端当前周期替代 5 小时窗口（周/月/日由服务端返回），不显示 5 小时条；每块下方显示最近刷新时间与刷新间隔。
  - 失败时下方两行内短文案提示。
  - Codex 新模型若尚未进入价格表，今日/本周费用显示为 `—`，不再伪装成 `$0`。
- 关闭两个服务时显示"未启用任何服务 / 到「设置 → 账号」开启"占位。
- 状态点阈值：以当前额度刷新间隔为基准，age ≤ 1.5× 间隔为 live，≤ 3× 为 stale，超过为 offline。

## 4. 桌面悬浮窗（Floating HUD）

- 设置里可勾选「显示悬浮窗」。
- 默认两行 pill，可扩展到三行：
  - 第一行：Codex 5 小时剩余百分比（18pt tile + 进度条 + 大字百分比）。
  - 第二行：Claude 5 小时剩余百分比。
  - 第三行：Grok 云端当前周期剩余百分比。
- 行可分别开关，结果只显示一行 / 全部隐藏。
- 样式：14pt 圆角 + `.popover` material + 0.5pt hairline 描边；无标题栏；不抢焦点；可拖动；始终置顶。
- 位置记忆：拖动后写回 UserDefaults；屏幕外重启时回落到默认右上角。
- 拖到距屏幕边缘 20pt 以内自动吸附到该边。

## 5. 自动后台刷新

- 后台两条独立循环：
  - 额度 API 循环：默认 2 分钟，可选「1m / 2m / 3m / 5m / 10m」。
  - 本地 JSONL 扫描循环：默认 2 分钟，可选「1m / 2m / 3m / 5m / 10m」。
- 端点：
  - Codex：`GET https://chatgpt.com/backend-api/wham/usage`，带 `ChatGPT-Account-Id` 头。
  - Claude：`GET https://api.anthropic.com/api/oauth/usage`，带 `anthropic-beta: oauth-2025-04-20`。
  - Grok：`GET https://cli-chat-proxy.grok.com/v1/billing?format=credits`，与 Grok CLI `/usage` 同一只读额度接口。
  - Gemini / agy：本机 `agy -p /usage --output-format json`（一次约 10–15 秒，同时得到两个池子）。定时刷新至少间隔 100 秒（默认跟随 2 分钟额度刷新），手动刷新不受此限；输出含 429 / RESOURCE_EXHAUSTED 时同样 10 分钟退避；失败保留已有快照。
  - Grok Bot：`POST https://api2.cursor.sh/aiserver.v1.DashboardService/GetSandUsageStatus`（未接通，见 §1）。
- 限流策略：
  - 同一服务两次成功之间至少 60 秒，周期性触发若间隔不足直接跳过。
  - 收到 429 后该服务进入 10 分钟退避，期间所有请求短路。
  - 手动「立即刷新」可绕过 60s 节流但仍遵守 429 退避。
- Claude API 失败且**完全没有可展示缓存**时，手动刷新会触发一次 Claude CLI 兜底（启动 `claude` 进程，向其 stdin 写入 `/usage`，解析输出），CLI 兜底也有独立 10 分钟冷却。
- Token 续期：Codex / Claude 双方均在 access_token 距离过期 5 分钟内时用 refresh_token 自动续期，并把新 token 写回原存储位置（文件或 Keychain）。
- 启动行为：先读本地额度缓存让 UI 立刻有数；首次刷新由调度器节奏触发；网络失败保留已有快照，仅以小字提示。

## 6. 本地用量统计

- 数据源：纯本地 JSONL，**额度 API 不返回历史数据**。
  - Claude：`~/.claude/projects/**/*.jsonl`,以及 Claude 桌面 App Cowork 会话的日志(`~/Library/Application Support/Claude/local-agent-mode-sessions/*/*/local_*/.claude/projects/**/*.jsonl`)，解析 `type=assistant` 行。云端 Projects 可额外开启接口同步（见文末）；普通 claude.ai 网页 / App 对话未接入。同一 `message.id` 跨文件全局去重（sidechain / subagent 会重复引用同一条），seen 集合上限 20000。
  - Codex：`~/.codex/sessions/**/*.jsonl` + `~/.codex/archived_sessions/**/*.jsonl`，按 `turn_context` 提供的当前 model 给随后的 `event_msg/token_count` 打标签；token 用 `payload.info.last_token_usage`，billable input = `input_tokens − cached_input_tokens`。
- 增量逻辑：每个文件按 `mtime + offset` 维护 watermark，未变化直接跳过；文件被截断时 offset 归零重扫，去重由全局 seen 兜底。
- 聚合：按 `(day, app, model)` 三元组在内存中累加；持久化到 `usage-rollup.json`。
- 价格表：在 `Core/Usage/Pricing.swift` 中硬编码，对齐 cc-switch / CodexBar 实测值，并补入 2026-10-08 官方价（Claude Fable 5 / 5.1、Opus 5 / 5.5、Sonnet 5 / 5.5、Opus / Sonnet / Haiku 4.x；GPT-5 至 GPT-5.6、GPT-6 Astra / Sol / Luna / 6.1 Sol，含 codex 变体）。命中不到的模型 cost 计 0，token 仍记录。模型名归一化：剥 `openai/` 前缀、`@YYYYMMDD` 或 `-YYYY-MM-DD` 日期后缀。

## 7. 主窗口 — 统计

## 9. 首次启动引导（Onboarding）

- 首次启动检测到 `SettingsStore.didCompleteOnboarding == false` 时弹出 4 步窗口（620×520，`.regularMaterial`）：
  1. Welcome：标题 + 简介。
  2. Detect accounts：展示自动识别的 Codex / Claude 账号、邮箱、plan，未识别时给出"请到终端登录"提示。
  3. Configure：菜单栏窗口 / 悬浮窗开关等关键设置一次性勾选。
  4. Ready：完成，按钮可直接进入"统计"或关闭。
- 完成后写入 `didCompleteOnboarding=true`，后续启动不再展示。

## 13. 风险 / 待持续关注

1. **非公开接口稳定性**：`wham/usage` / `oauth/usage` 字段可能随时调整，解析器需要保持容错。
2. **Keychain 弹窗**：首次读 `Claude Code-credentials` 系统会弹一次授权窗，引导文案已加。
3. **价格表漂移**：当前对齐 cc-switch / CodexBar 2026 上半年价位；模型迭代后需要同步。
4. **JSONL 量级**：长期使用后 `~/.claude/projects` 可达数百 MB；增量 watermark + seen ID 上限保证启动 / 扫描时间可控，但 seen 集合上限 20000 时若历史窗口超过该长度会有边缘重复风险。
5. **签名与公证**：发布前需 Apple Developer 证书；当前开发期未签名，README 标注「右键打开」。

### Claude 云端 Projects 用量（2026-10）

- 设置 → 刷新提供「同步云端用量」，默认关闭，复用当前本机 Claude Code 账号。首次同步回补本地昨天 00:00 起的记录，此后保留历史；正常至少间隔 5 分钟（跟随日志扫描触发），429 至少退避 10 分钟且遵守更长的 Retry-After。
- 仅接入 Projects beta 的 anthropic_cloud 会话（项目主会话和子任务）；Remote Control / bridge 仍由本机日志统计。普通 claude.ai 聊天不在范围内。
- Token 包含输入、输出、缓存读取和缓存写入。以服务端每轮 result 的累计用量差值统计，按结束日期归档，不按剩余额度倒推。跨午夜的一轮归入结束当天。费用采用服务端估算费用，用户自定义价格优先，不代表订阅实际扣款。
- 同一 message.id 同时存在云端和本机时，从合并统计中扣除已计的本地贡献。重复同步、重启、价格重算不能再次叠加云端历史。
- 错误保留已恢复数据并显示同步状态。只能恢复接口仍提供的会话；已删除、不可见或被截断的历史不补造。
